# Wordle 

Ett gulligt och responsivt **Wordle-inspirerat spel** byggt med **vanilla JavaScript, HTML och CSS**.  
Projektet är gjort som en övning i DOM-manipulation, events, animationer och spel-logik

---

## 🎮 Om projektet

Wordle är ett ordspel där spelaren ska gissa ett slumpmässigt ord på **5 bokstäver** inom **6 försök**.

Spelet:
- Accepterar input både via **tangentbord** och **virtuellt keyboard**
- Visar visuella hints med färger (rätt, fel plats, fel)
- Har animationer för fel, rätt och vinst
- Visar alerts för feedback
- Har en **Starta om-knapp** när spelet är slut

---

## ✨ Funktioner

- ✅ Slumpmässigt valt målord
- ⌨️ Stöd för både mus & tangentbord
- 🎨 Färgkodade bokstäver (correct / wrong-location / wrong)
- 💃 Animationer:
  - Flip-animation vid gissning
  - Shake vid felaktig input
  - Dance-animation vid vinst
- 🚨 Alerts för feedback
- 🔁 Retry-knapp för att starta om spelet
- 📱 Responsiv design (mobil & desktop)

---

## 🛠️ Tekniker som används

- **HTML5**
- **CSS3**
  - Grid & Flexbox
  - Animationer (`@keyframes`)
- **JavaScript**
  - DOM-manipulation
  - Event listeners
  - Dataset attributes
  - Timing med `setTimeout`
